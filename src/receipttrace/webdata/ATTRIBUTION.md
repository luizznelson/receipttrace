# Public demonstration data

The three original PNGs and receipt-derived extraction results come from CORD v2, by the CORD authors (NAVER CLOVA).

- Authors and project: https://github.com/clovaai/cord
- Dataset: https://huggingface.co/datasets/naver-clova-ix/cord-v2
- Revision: 7f0115a4b758a71d6473b8d085751692da2fef98
- License: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/
- Selected images: first training shard, rows 6, 59 and 173.
- Transformations: none to the encoded image bytes; extraction results are derived data. Reports preserve the original published bytes.

These examples were selected manually to illustrate OCR failures. They are not a representative sample. Summary metrics use all 20 development documents, not these three examples. No Brazilian fiscal-compliance claim is made.

Dataset licensing is independent of code licensing. Images must retain this attribution when redistributed. No receipt reference files or API keys are bundled.
